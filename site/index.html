richmod

Problem
Household money lives in emails, chat messages and paper, and nobody can say where it went.
Built
A self-hosted finance system that turns emails, Telegram messages and documents into an auditable ledger.
The hard part

agenticform

TypeScript
Problem
Every coding agent (Claude Code, Codex, OpenCode and the rest) has its own interface, so anything that drives them is rewritten per agent, and running one on a shared machine is a risk.
Built
One execution fabric for eight agent harnesses: a library, HTTP API, CLI and MCP server over a hub and outbound-only nodes. Switching agents is a one-line change.
The hard part
Safe by default. Every harness runs in a bubblewrap sandbox, and a node whose sandbox self-test fails refuses all runs rather than run unsandboxed. Commands hit a durable ledger before any effect. Inside that boundary the agent runs freely by default; a run can opt in to having an owner answer each permission request remotely, or to refusing them all.

sorot

TypeScript
Problem

Built
A local pipeline that transcribes long YouTube or local videos, scores candidate moments, renders vertical 9:16 clips with word-timed captions, and feeds real performance data back into its ranking.
The hard part
Choosing the moments. Whisper transcripts feed an explainable score, so every pick can be traced back to why it was chosen; an LLM is optional and everything runs on your own machine.

Agent infrastructure

six mechanisms in use, each with the failure it prevents

01

Agent-to-agent handoff

Work passes between agents with its context and chat attached, and the reply comes back in the same thread.

Preventswork arriving as a bare sentence with the reasoning stripped off.

02

Missions

A multi-ticket job runs inside one worktree, in its own turns, for as long as it takes.

Preventsa long job dying halfway with its state only in a chat log.

03

Scheduled cron jobs

A job runs on a schedule and speaks only when something is wrong.

Preventsa silent failure being found by a person weeks later.

04

Delegation to a coding agent

A lead agent briefs a coding agent in its own session and working tree, then verifies the result.

Preventstwo agents editing one file, and a claim of “done” going unchecked.

05

The review gate

A reviewer agent checks every pull request on the exact commit; nothing merges until it passes.

Preventsan unreviewed change reaching a deployed service.

06

One owner per task

Each task is assigned to exactly one agent and one branch.

Preventsa merge conflict discovered at merge time.

Each path ends at something that checks or someone who decides. A handoff carries its own context, a change stops at the review gate, a scheduled job reports only failures, and a deploy does not start without a person saying so.
